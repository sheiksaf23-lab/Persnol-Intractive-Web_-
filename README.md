# 🌐 Personal Interactive Web

A modern and interactive personal portfolio website built using **HTML, CSS, and JavaScript**. This project showcases my profile, skills, projects, and creativity with smooth animations and an engaging user experience.

## ✨ Features

- 🎨 Modern and responsive UI
- 🖼️ Interactive image gallery
- 🎵 Background music support
- 💫 Smooth animations and transitions
- 📱 Mobile-friendly design
- ⚡ Fast and lightweight
- 👨‍💻 Personal introduction section
- 🚀 Easy to customize

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
